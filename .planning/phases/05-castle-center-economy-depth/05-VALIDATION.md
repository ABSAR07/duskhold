## Sampling Rate

- **After every task commit:** Run `bash tools/test.sh -gselect=<the task's scripts>` and, for anything under simulation/ or data/, the smoke, army, walls and economy replays (and full_idle against the report's digest)
- **After every plan wave:** Run `bash tools/test.sh` and `bash tools/lint.sh` (the orchestrator's post-merge gate, logged to build/test-results/postmerge_test_stdout.log; eleven waves, all green)
- **Before `/gsd-verify-work`:** Full suite must be green (it is: 279 scripts, 2653 tests, 60629 asserts, all passing, lint clean on 446 files: the orchestrator's wave-11 post-merge gate of 2026-10-22T09:37:47Z on commit 6679a32; plan 05-12's own run on 82928bd gave 60264 asserts and the wave-10 gate 60608 with the same 2653 tests, so the assert count varies by a few hundred between runs of the same code (per-frame assertions in e2e tests) and the script and test counts are the stable figures; CI run 39751537305 green on 570ff8d; after gap round 1 (plans 05-13 to 05-24): 281 scripts, 2668 tests, all passing, lint clean on 448 files (plan 05-24's closing pass and the orchestrator's gates after waves 10 and 11, 2026-10-25); the round is not yet pushed, so no CI run covers it)
- **Max feedback latency:** 90 s for a single script; the full suite is accepted at about 15 minutes
