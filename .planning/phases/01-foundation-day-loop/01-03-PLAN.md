## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local repo → public GitHub | Everything in history becomes world-readable and permanent |
| GitHub Actions runner ↔ third-party actions and downloads | Workflow code, actions/*, PyPI and Godot release downloads execute with the workflow token |
| Pull requests → CI | Untrusted contributor code could run in CI |
