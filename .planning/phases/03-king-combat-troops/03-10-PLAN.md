</objective>

The pack and the prompts that show it are one capability: without Task 2 the tiles are unused, without Task 1 the prompts have nothing to show. `gsd-tools estimate-check --tokens 125000` reports 1.25x the 100k smart-zone budget; the check is advisory, never a block. Plans run one executor at a time on the main checkout, so the file count creates no parallel conflict; the binding limit is one executor's context, and Phase 2's 33-path plan 02-01 ran inside one executor (19 min, 02-01-SUMMARY). Splitting would renumber every later plan, whose actions cross-reference each other by number.

Re-slice if needed: should an executor run short of budget, the plan splits at the Task 1 / Task 2 boundary inside 03-10 (the executor stops after Task 1's commit and a fresh executor resumes at Task 2), so no later plan is renumbered.
