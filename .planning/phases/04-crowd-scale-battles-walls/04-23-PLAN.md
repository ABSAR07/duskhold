<exact_port_rules>
Restated in every port plan (04-15 to 04-20, 04-23):
1. Vector2 is godot::Vector2 with real_t float (precision single). Every GDScript float (scalars, radii, ranges, speeds, a method result once it leaves the method, PackedFloat64Array elements) is double in C++; GDScript int is int64_t.
2. Narrow exactly where GDScript narrows: a scalar meeting a Vector2 is cast to real_t at that operator; a Vector2 method result is widened to double as it leaves. Keep each expression's operation order and grouping; never reassociate or hoist a subexpression that changes rounding.
3. GDScript utilities and Vector2 methods only as native/src/gd_math.h's table allows (plan 04-15 proved each bit-equal to the engine).
4. Ascending id or index order everywhere, ties broken exactly as the GDScript does (a strict < keeps the earlier); no unordered containers; any sort ends with the id.
5. Candidate sets equal the GDScript's wherever membership or order can change an answer; a superset is allowed only where the code takes a strict minimum over an exact test.
6. No FMA and no fast math; only + - * / and sqrt; test_native_rules_guard enforces it.
7. Pins first: before native code replaces a GDScript body, a GUT test pins the GDScript outputs on seeded inputs (sha256 of the packed results), committed on its own while the GDScript runs; the native version must pass it unchanged; a pin is never edited during the port.
8. One implementation ships: when pins and goldens hold, the GDScript body is deleted in the same plan; no runtime fallback.
9. Goldens: smoke 2599c7c2 (703 ticks), army f7a967ed (1353) and walls bfb05fc7 (1961) against tests/golden, full_idle 4385f569 (6911) twice, the gate digest e448ffdb with GATE_OK 300/300/0. Never regenerate; any move stops the plan before the commit, with the scenario and digests reported (only an owner checkpoint:decision can sanction a regeneration).
10. Every native method checks sizes and indices that cross from GDScript and answers what the GDScript answered for bad input (-1, Vector3i(0, 0, 0), MAX_TICKS) instead of reading out of bounds.
11. GDScript references native classes by the rule recorded in 04-14-SUMMARY.
</exact_port_rules>
