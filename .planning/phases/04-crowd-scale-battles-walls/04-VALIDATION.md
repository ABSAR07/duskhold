## Sampling Rate

- **After every task commit:** Run `bash tools/test.sh -gselect=<the task's scripts>` and, for anything under simulation/, the smoke, army and walls replays
- **After every plan wave:** Run `bash tools/test.sh` and `bash tools/lint.sh` (the orchestrator's post-merge gate, logged to build/test-results/postmerge_test_stdout.log)
- **Before `/gsd-verify-work`:** Full suite must be green (it is: 221 scripts, 2076 tests, 54978 asserts, exit 0 after plan 04-27 at e0ecde0; CI run 39445109146 green on every job; plan 04-28 changed only `.planning/`, so that gate stands. Earlier figures: 211 scripts, 1979 tests, 34047 asserts after plan 04-20 at b5a6f57, CI run 39310876191; 190 scripts, 1794 tests, 27554 asserts at a8c57ab, CI run 38959046206)
- **Max feedback latency:** 90 s for a single script; the full suite is accepted at about 10 to 12 minutes
