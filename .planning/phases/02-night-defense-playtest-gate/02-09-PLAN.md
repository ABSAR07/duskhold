ROADMAP Goal (verbatim; the ROADMAP line is not in user-story format and no story is invented here — flagged to the orchestrator): "The prototype map plays the full day → night → dawn loop. The player sees each night coming and starts it deliberately, defends with the king and basic towers, rebuilds and collects income at dawn, and wins or loses on a results screen. Seeded nights replay deterministically, and the owner confirms the loop is fun before anything is built on top of it."

Purpose: every later change to the night simulation is caught by a digest mismatch; the open question whether Linux reproduces the Windows digest (RESEARCH Open Question 6) is answered by the first CI run, with the per-platform fallback carried out if needed.

Output: ReplayScenarios, replay_cli.gd, tools/replay.sh, three smoke fixtures, the golden file, two tests, the CI step, and a green CI run on the pushed branch.
</objective>

```gdscript
class_name ReplayScenarios extends RefCounted
const NAMES: Array[StringName] = [&"smoke", &"full_idle"]
const GOLDEN_DIR := "res://tests/golden"
static func has(name: StringName) -> bool
static func default_seed(name: StringName) -> int
static func run(name: StringName, run_seed: int) -> Dictionary      # ReplayDriver result
static func golden_digest(path: String) -> String   # platform key OS.get_name() first, then "default"; "" if none
```
CLI user args (after `--`): `--scenario=<name>` (required), `--seed=<int>`, `--twice`, `--expect-file=<path under tests/golden/>`, `--out=<dir under build/>` (default build/replay), `--write-golden` (writes the `default` key of tests/golden/<scenario>.json).
Exit codes: 0 pass (prints `REPLAY_OK scenario=<n> seed=<s> outcome=<o> ticks=<t> digest=<hex>`), 1 mismatch, timeout outcome or failure (`REPLAY_MISMATCH ...` / `REPLAY_GOLDEN_MISMATCH platform=<os> expected=<hex> actual=<hex>` / `REPLAY_FAILED ...`), 64 usage. The wrapper adds 3 (Godot missing) and passes through 124 (timeout).
Golden file: `{"scenario": "smoke", "seed": 1, "digests": {"default": "<hex>"}}`; a platform key such as `"Linux"` is added only if CI disagrees.
